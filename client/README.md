# Employees — client

React single-page app for the [Employees](../README.md) product (auth, employee list, CRUD).

See the **root [README](../README.md)** for product overview, stack, local setup, and API documentation.

## Client-only commands

From this directory:

| Script | Purpose |
|--------|---------|
| `npm run dev` | Development server (CRA, port 3000) |
| `npm run build` | Production build to `build/` |
| `npm test` | Jest / Testing Library |

In development, the API base URL is configured in `src/app/services/api.ts`.
